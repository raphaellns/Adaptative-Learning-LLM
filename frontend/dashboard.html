PROJETO

Sobre o Adaptive Learning

Um sistema de aprendizagem adaptativa baseado em inteligência artificial.

Objetivo

O projeto busca utilizar modelos de linguagem para analisar respostas de estudantes, identificar suas dificuldades e gerar recomendações personalizadas de estudo.

Tecnologias

Python FastAPI PostgreSQL SQLAlchemy Ollama Qwen3 HTML CSS JavaScript
